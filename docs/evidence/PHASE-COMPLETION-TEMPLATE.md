# Phase completion evidence template

Copy this file to `docs/evidence/P<n>-<short-name>.md` when a phase is ready for review.

- Phase: `P<n>` (replace with the exact phase ID, such as `P0`)
- Date: `YYYY-MM-DD`
- Commit: `<git SHA>`
- Device/runtime: `<exact environment or N/A>`
- Gate: PASS or FAIL

## Acceptance criteria

- [ ] List each roadmap acceptance criterion and the evidence that satisfies it.

## Evidence

- Link logs, command output, CI runs, or device observations. Redact credentials and private data.
- Distinguish source review, host checks, emulator checks, and physical-device results.

## Known limitations

- List unresolved issues, unsupported cases, and follow-up work.
